## 🕹️ About The Project

This portfolio is built as a nostalgic throwback to the CRT era, featuring:

*   **📺 CRT Simulation**: Authentic scanlines, chromatic aberration, and screen curvature effects.
*   **🎛️ Channel Switching**: Navigate through my professional life by changing "channels" (Landing, About, Experience, Projects, etc.).
*   **🔊 Immersive Audio**: Background static and satisfying click sounds for a tactile feel.
*   **⚡ Modern Tech**: Built with high-performance modern web technologies disguised as vintage hardware.

## 🚀 Getting Started

Want to tune in locally?

1.  **Clone the frequency:**
    ```bash
    git clone https://github.com/SiddarthaKoppaka/Portfolio.git
    cd portfolio
    ```

2.  **Install the receiver modules:**
    ```bash
    npm install
    ```

3.  **Power on the TV:**
    ```bash
    npm run dev
    ```
